环境、工具与进阶路线

三件收尾的事：把仓库里唯二需要 MySQL 的工程跑起来，备齐顺手的工具，以及读完这 16 章之后往哪走。

D.1 给 ssh_ch12_ex2 / ex3 准备 MySQL

仓库里只有这两个工程需要真实的 MySQL，其余涉及数据库的工程都用 H2 内存库。它们的配置写死了三件事：连 localhost 默认端口、库名 spring_start_here、用户 root 且密码为空。书的附录 E 用了八页截图讲安装 MySQL 和 MySQL Workbench；有 Docker 的话一条命令就够。

用 Docker 起一个符合上述配置的 MySQL
docker run --name ssh-mysql -d -p 3306:3306 \
       -e MYSQL_ALLOW_EMPTY_PASSWORD=yes \
       -e MYSQL_DATABASE=spring_start_here \
       mysql:8

# 等十几秒让它初始化完，然后：
cd ssh_ch12_ex2 && ./mvnw spring-boot:run

# 用完删除
docker rm -f ssh-mysql

已经装了本地 MySQL 的话，登录后执行 CREATE DATABASE spring_start_here; 即可。如果你的 root 有密码，改这两个工程 application.properties 里的 …datasource.password。表不用手工建，schema.sql 会在启动时执行。

书里的库名不一样 书的附录 E 建的库叫 spring_quickly，仓库的配置里用的是 spring_start_here。以仓库为准。

D.3 学完这 16 章，你会了什么、还不会什么

本书的定位是“入门并且学扎实”。读完之后，你能读懂一个典型 Spring Boot 后端项目的大部分代码，能独立写带数据库的 REST 服务并给它写测试。下面这些是真实项目里常见、而本书没有覆盖或只是一笔带过的主题，按建议的学习顺序排列。

顺序主题为什么要学本书里的伏笔
1参数校验
Bean Validation，@Valid		任何接收外部输入的接口都需要。几个注解就能把校验规则声明在对象上，校验失败自动返回 400第 8 章提到的 @Valid；第 10 章的 @RestControllerAdvice 用来统一校验错误的格式
2Spring Security第 9 章的手写登录不能用于生产。认证、授权、CSRF、密码加密都由它负责第 9 章的登录示例；第 6 章说的“方法级鉴权也是 AOP”
3Spring Data JPA
Hibernate		业界使用最广的持久层方案，处理对象之间的关联关系比 Spring Data JDBC 强得多第 14 章的 Repository 接口、派生查询，编程模型相同
4数据库版本管理
Flyway / Liquibase		生产库不能靠 schema.sql 每次重建。迁移工具让表结构的每次变更都有版本、可追溯第 12 章的 schema.sql
5配置进阶多环境、密钥管理、@ConfigurationProperties、条件装配第 7 章 7.4 节
6可观测性
Actuator、日志、指标		应用上线后要能回答“它还活着吗、慢在哪、错在哪”第 6 章用切面打日志
7测试进阶
Testcontainers、切片测试		用真实数据库的容器跑集成测试；@WebMvcTest 这类只启动一部分上下文的测试更快第 12 章自测、第 16 章
8打包与部署
可执行 jar、容器镜像		把应用送上服务器第 7 章 7.4 节的 java -jar
9异步与消息
@Async、@Scheduled、Kafka / RabbitMQ		不是所有事都该在一次 HTTP 请求里同步做完第 4 章的“发通知”就是典型的该异步化的操作
10Spring Cloud 与响应式服务多了之后的服务发现、网关、熔断；以及 WebFlux第 11 章的 OpenFeign 与 WebClient；附录 B
怎么学最省力 挑仓库里现成的工程往上加。比如在 ssh_ch14_ex1 上：先给转账请求加 @Valid 校验金额大于 0，再用 @RestControllerAdvice 把 AccountNotFoundException 变成 404，再加 Spring Security 保护 /transfer，最后把 Spring Data JDBC 换成 JPA。每一步都有现成的测试帮你确认没改坏。
