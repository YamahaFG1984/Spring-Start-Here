Spring Start Here · 第 2 版代码 · 中文精读手册

用 Spring Boot 4 重读
《Spring Start Here》

这份手册把 Laurenţiu Spilcă 那本 Spring Start Here 的 16 章内容（外加附录），按本仓库里 66 个 Maven 工程的实际代码重讲了一遍。书出版于 2021 年（Spring 5.2 / Boot 2.3 / Java 11），仓库已经升级到 Spring Framework 7.0.1 / Spring Boot 4.x / Java 25——凡是两者对不上的地方，本手册一律以代码为准，并单独标出差异和背后的原因。

怎么用这份手册

建议路线顺序读第 1–6 章

Spring Core 是地基。这六章占全书一半篇幅，跳过它们，后面每个特性都会像魔法。

 建议路线第 7 章起边跑边读

每章都有「动手练习」，给了可直接粘贴的 curl 和 mvnw 命令。看到现象再回头读原理，效率高得多。

 建议路线第 15–16 章随时可看

测试相关的类散落在 ch9、ch14 工程里。读完第 4 章（依赖注入）就可以提前看第 15 章。

 建议路线HTTP / JSON 不熟先看附录 A

第 7–11 章默认你懂请求、响应、状态码和 JSON。二十分钟补齐，后面省很多力气。

 随手查遇到报错翻附录 C

按控制台里的关键词查原因和解法；另有全书注解速查和术语表。
每章的固定结构 ① 本章对应的仓库工程清单 → ② 概念讲解（配图）→ ③ 逐段读代码 → ④ 与书中旧版的差异对照 → ⑤ 动手练习 → ⑥ 自测问答。差异部分用蓝色卡片标"书中"、绿色卡片标"仓库"，下面跟一段"为什么变"。

照书抄代码时最容易被绊倒的四处

十六章导航

01 · 基础真实世界中的 Spring

为什么用框架、生态全景、什么时候不该用。无代码工程。

 02 · 基础Spring 上下文：定义 bean

@Bean、@Component + @ComponentScan、registerBean 三种方式。

 03 · 基础Spring 上下文：装配 bean

五种注入方式、@Configuration 的 CGLIB 代理、循环依赖、@Qualifier。

 04 · 基础Spring 上下文：使用抽象

面向接口解耦、哪些类该进上下文、@Service / @Repository。

 05 · 基础Bean 作用域与生命周期

单例 vs 原型、饥饿与懒加载、"单例注入原型"这个经典陷阱。

 06 · 基础用 Spring AOP 实现切面

代理机制、切点表达式、切面链与 @Order。理解后面所有注解的钥匙。

 07 · 实现理解 Spring Boot 与 Spring MVC

Servlet 容器、DispatcherServlet、starter、自动配置、第一个网页。

 08 · 实现用 Boot + MVC 实现 Web 应用

Thymeleaf 动态视图、@RequestParam / @PathVariable、GET 与 POST。

 09 · 实现使用 Spring Web 作用域

request / session / application，以及作用域代理如何工作。

 10 · 实现实现 REST 服务

@RestController、ResponseEntity、@RestControllerAdvice、OpenAPI。

 11 · 实现消费 REST 端点

RestClient（新）、OpenFeign、RestTemplate、WebClient 四选一。

 12 · 实现在 Spring 应用中使用数据源

DataSource 与连接池、JdbcTemplate、三种配置数据源的方式。

 13 · 实现在 Spring 应用中使用事务

@Transactional 的代理机制，以及三个必踩的坑。

 14 · 实现用 Spring Data 实现持久化

Repository 接口、派生查询、@Query / @Modifying。

 15 · 实现单元测试

Mockito、@Mock / @InjectMocks。本章没有 Spring。

 16 · 实现Spring 集成测试

@SpringBootTest、@MockitoBean、MockMvc 与断言速查。

环境准备

开跑前确认

java -version     # 必须是 JDK 25（第 2–6 章的 static void main() 依赖它）
mvn -version      # 3.9+；第 7 章起的 Boot 工程也可以用自带的 ./mvnw

# Spring Core 工程（第 2–6 章）：IDE 里直接运行 Main 类
# Boot 工程（第 7 章起）：
cd ssh_ch7_ex1 && ./mvnw spring-boot:run

第 12–14 章默认用 H2 内存库，不需要安装 MySQL；只有 ssh_ch12_ex2 和 ssh_ch12_ex3 需要本地 MySQL 并建库 spring_start_here。

关于本仓库的三处小瑕疵 ① ssh_ch10_ex5 的父 POM 还停在 spring-boot-starter-parent 3.4.1，依赖也还是旧名 spring-boot-starter-web / -test——照样能跑，想统一的话改这三处即可，代码不用动。
② ssh_ch11_ex4 没有配 server.port，默认 8080 会和 ssh_ch11_payments 冲突，跑之前先加一行 server.port=9090。
③ ssh_ch11_payments 的 spring.application.name 写成了 ssh_ch1_payments（少了个 1），无害的笔误。
